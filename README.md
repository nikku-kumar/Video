# Aanya Birthday Surprise

A Vite-compatible vanilla JavaScript prototype inspired by the 21-state Instagram Reel brief.

## Run

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Notes

- The experience runs at a portrait 9:16 presentation ratio and is responsive on smaller screens.
- All 21 timeline states are represented in `src/main.js`.
- Source photos, audio, exact letter copy, and branding are intentionally represented as editable placeholders because the original media was not included.
- Use the bottom controls to navigate manually or start the timed sequence.
